# Long-horizon research and ecosystem branches

Research branches include cross-model semantic reproduction, interaction-aware
trigger search under unbounded spaces, calibrated causal attribution, and
hard-to-observe sensor coverage. Engineering branches include stronger sandbox
backends, user-controlled distributed workers, long-fuse campaigns, persistent
browser sessions with opaque secret handles, safe multi-agent environments, and
large composition studies.

Standards work tracks OpenTelemetry GenAI/MCP conventions and MCP protocol
revisions. SOVA extensions are proposed only after implementation evidence;
neutral specifications and compatibility kits must remain independently
implementable.

Explicit OSS non-goals are TAFAAR, TRS/EAL/MPL/underwriting/premium logic,
independent attestation or certificate issuance, private corpora, confidential
client stores, a hosted TRUSCOR control plane, automatic remediation, and any
claim that bounded testing proves universal safety.
