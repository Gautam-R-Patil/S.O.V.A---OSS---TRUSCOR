# User pathways

- Developer: `init` → `doctor` → `map` → `check` → `ci`.
- Security engineer: target manifest/plan → gated execution → evidence →
  forensics → coordinated disclosure.
- Researcher: author `.sova` → repeated traces → `replay study` → export safe
  artifacts → cite the exact release and methodology.
- Platform/compliance team: local evidence bundle → offline verification →
  selective disclosure. SOVA output is self-assessment, not TRUSCOR attestation.
- Agent or MCP host: inspect the pinned tool manifest, establish the separate
  control directory, then serve local stdio MCP.
- Contributor: conformance kit → safe fixture or adapter → provenance record →
  DCO-signed pull request.

Every pathway retains uncertainty, detection-floor, safety, and authorization
information. Stars, downloads, or a successful demo are not research evidence.
