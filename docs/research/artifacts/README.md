# Research artifact index

`index.toml` is the permanent public index for cleared protocols, datasets,
run bundles, negative results, analysis code, papers, and replication packages.

An index entry records:

- immutable ID, version, and SHA-256 digest;
- artifact type and evidence state;
- protocol, methodology, schema, taxonomy, code, target, and baseline versions;
- provenance, licence, ethics/authorization, safety, and disclosure status;
- storage locator and independent reproduction status;
- limitations, supersession, withdrawal, or correction.

The index is currently empty because no SOVA experiment has run. Creating the
home is not evidence of a result.

Restricted invention records, private targets, client data, embargoed findings,
and raw private traces never appear here.
