# Private invention intake

Invention disclosure is intentionally **not** a public GitHub issue form.
Public issue bodies, titles, attachments, comments, and notifications can
destroy confidentiality before an IP decision is made.

## Private route

Send a minimal message to [gautam@truscor.org](mailto:gautam@truscor.org) with
the subject:

```text
[SOVA INVENTION REVIEW] Short non-confidential title
```

The first message should contain only:

- contributor name and preferred private contact;
- the affected public topic or component;
- whether code or a public disclosure already exists;
- time sensitivity;
- a request for a protected exchange method.

Do not send the full mechanism, private target data, client material, secrets,
patent claims, or confidential third-party information through a public issue
or ordinary email.

## Restricted ledger

The working invention ledger lives under the ignored
`private/invention-ledger/` path. It records:

- inventors, ownership, and contributor/employment obligations;
- conception and reduction-to-practice dates;
- the narrow mechanism and alternatives;
- prior art and differences;
- experiments and enabling detail;
- public, patent, defensive-publication, or trade-secret disposition;
- every disclosure and deadline;
- qualified counsel and founder decisions.

Only a cleared, generic public decision may be extracted into this repository.
The private record is never copied and “anonymized” into Git.

## Gate

Before code, a paper, a preprint, a talk, an issue, a demo, or a benchmark
reveals a potentially non-trivial mechanism, complete the
[publication and IP review](./publication-and-ip-review.md). Uncertainty means
hold and review; it does not establish patentability.
