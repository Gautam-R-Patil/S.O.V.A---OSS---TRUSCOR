# SOVA OSS governance

SOVA OSS is maintained in public by the people listed in [MAINTAINERS.md](MAINTAINERS.md).
TRUSCOR Private Limited sponsors the project but public technical decisions,
security boundaries, release evidence, and conflicts of interest must remain
reviewable from the repository.

Changes use pull requests, required CI, DCO sign-off, CODEOWNERS review, and the
public/private boundary check. Schema, taxonomy, methodology, safety,
authorization, cryptography, and release-policy changes require an explicit
decision record and compatibility analysis. No maintainer may bypass
coordinated disclosure, founder IP review, or human authorization through an
undocumented exception.

The Apache-2.0 licence governs code; `TRADEMARKS.md`, `DUAL_USE_POLICY.md`,
`SECURITY.md`, and the Code of Conduct govern their respective project
surfaces. Maintainer appointment, removal, succession, and release authority
are documented in `MAINTAINERS.md` rather than inferred from employment.
